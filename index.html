Life Mall Game

Welcome to my project! This is a Python life simulation game where you work, shop, travel, and upgrade your life.

About the Game

This project is written in Python and is not playable in the browser. To play the game, download the Python file from the repository and run it on your computer.

How to Play

  1. Download the .py file from the repository.
  2. Install Python on your computer.
  3. Run the game using the command: python life_mall_game.py
